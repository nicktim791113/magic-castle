# 📐 魔法小皇宮 — 開發文件

專案的架構與擴充說明，供開發時參考。**改動架構時請同步更新本檔。**

---

## 技術總覽
- **純前端**：HTML + CSS + 原生 JavaScript（無框架、無建置工具，雙擊即可開）
- **圖形**：emoji + 手繪 inline SVG（不需任何圖檔）
- **音效**：Web Audio 即時合成（不需任何音檔）
- **PWA**：`manifest.webmanifest` + `sw.js`（離線可玩、可安裝到桌面/主畫面）
- **部署**：GitHub Pages（`main` 分支根目錄，`git push` 後約 1 分鐘自動上線）

---

## 檔案職責
| 檔案 | 負責什麼 |
|---|---|
| `index.html` | 主入口，三座城堡（SVG）連到各遊戲 |
| `dressup.html` + `js/dressup.js` | 換裝舞臺；**公主＋王子**（角色系統）。娃娃身體與臉 SVG 在 html，髮型/服裝等素材與邏輯在 js |
| `memory.html` + `js/memory.js` | 記憶配對；卡片翻牌、兩種模式、三種難度 |
| `match.html` + `js/match.js` | 關係配對；**連連看（20 組，`PAIRS`）**＋**聲音配對（聽叫聲選動物，`SOUND`）**；物件可用 `assets/img/`，音檔在 `assets/sound/`。素材清單見 `docs/美術素材清單.md` |
| `maze.html` + `js/maze.js` | 迷宮闖關；canvas 迷宮（遞迴回溯生成）＋對應配對。指標拖曳移動＋彩虹軌跡；幼兒描繪模式（`TRACE` 形狀庫）。鍵盤／方向鍵／拖曳 |
| `cards.html` + `js/cards.js` | 貝兒數字挑戰；撲克牌累加心算，難度＝牌數（`DIFFS` 花色套數），含觸控數字鍵盤 |
| `tictactoe.html` + `js/tictactoe.js` | 花木蘭井字棋；經典 3×3＋終極 9×9（巢狀），倒數計時、計分、投降，`window.__ttt` 測試接口 |
| `math.html` + `js/math.js` | 數數樂園（數學認知）；情境背景數物件選數字。主題＝`THEMES`、難度（數量範圍/選項數）＝`DIFFS`；情境背景樣式在 `math.html` 的 `.scene.xxx` |
| `css/style.css` | 共用主題（顏色變數、按鈕、動畫、慶祝彈窗、搖晃） |
| `js/common.js` | 共用工具：音效 `Sound`、彩帶 `confetti`、慶祝 `celebrate`、天空背景、SW 註冊、鎖定縮放／防選取（`lockZoom`）、圖片素材 `iconEl`／`coverImg`（缺圖退回 emoji）、`playClip` 播放音效 |
| `sw.js` | Service Worker：預先快取 + stale-while-revalidate |
| `manifest.webmanifest` | PWA 設定（名稱、圖示、顏色、起始路徑） |
| `icons/` | App 圖示；由 `assets/icongen.html` 用瀏覽器轉檔產生 |

## 常見擴充點（多為 🟢 小型修改）
- **換裝加服裝/髮型**：`js/dressup.js` 的 `PRINCESS_OUTFITS`／`PRINCE_OUTFITS`、`PRINCESS_HAIRS`／`PRINCE_HAIRS`（依角色分）；共用的 `SHOES` / `HEADWEAR` / `SKINS` / `SCENES`。王子西裝可用 `princeSuit()` 換顏色。切角色的預設見 `DEFAULT_HEAD` / `DEFAULT_SHOES`。
- **記憶卡圖案**：`js/memory.js` 的 `POOL`（emoji 清單）。難度設定：`DIFFS`。
- **關係配對的題目**：`js/match.js` 的 `PAIRS`（動物↔食物）。難度設定：`DIFFS`。
- **迷宮題目**：`js/maze.js` 的 `THEMES`（`animal`／`letter`／`shape` 各自的 `pairs`）。難度（迷宮大小、誘餌數）：`DIFFS`。
- **幼兒描繪形狀**：`js/maze.js` 的 `TRACE` 陣列，每個 `{name, make()}` 的 `make()` 回傳路徑點陣列（用 `linePts`/`samplePts`/`polyPts`）。
- **數數樂園主題**：`js/math.js` 的 `THEMES`（情境名／背景 class／物件 emoji／問句）；難度（數量範圍、選項數）在 `DIFFS`，背景樣式在 `math.html` 的 `.scene.xxx`。
- **主題配色**：`css/style.css` 最上面的 `:root` 顏色變數。

## 改到這些 = 🔴 大型修改（記得先備份）
- `js/common.js`、`css/style.css`：**全站共用**，改壞會影響每一個頁面。
- `sw.js`、`manifest.webmanifest`、`icons/`：PWA 與快取。
  - 改完 `sw.js` 記得把快取名稱 `mlp-cache-v1` 版本號 +1，使用者才會更新到新版。
  - 新增/刪除檔案時，記得同步更新 `sw.js` 裡的 `ASSETS` 預快取清單。
- **路徑**：全站一律使用**相對路徑**，確保在 `/magic-castle/` 子路徑下正常運作（這是 GitHub Pages 能成功的關鍵）。
