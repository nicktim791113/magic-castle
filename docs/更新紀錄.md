## [1.2.0] － 2026-06-07｜用 ChatGPT 重畫遊戲美術（第一批：數數樂園）🎨🤖
### 新增／替換
- 依使用者要求，**改用 ChatGPT（GPT 生圖）親自繪製遊戲美術**，覆蓋先前自製的 SVG 版插畫（同檔名）
- 第一批完成 **數數樂園 12 張**：
  - 6 張場景背景（1024×640 滿版）：`scene-ocean / garden / sky / night / orchard / pond`（夜空不含星星，中間留空放物件）
  - 6 個可數物件（512×512 去背）：`obj-fish / flower / butterfly / star / apple / duck`
- 另外順手共用到其他遊戲：`m-cat`、`a-cat`、`m-butterfly`、`m-star`、`m-apple`、`a-duck`（同一張圖存多檔名）

- 用 Chrome 操作 `chatgpt.com` 生圖 → 頁內 `fetch`→`blob` 觸發下載 → Pillow 自動去背裁邊／縮圖（物件 512²、背景 1024×640 cover）→ 存入 `assets/img/`
### 影響檔案
- 替換 `assets/img/*.png`（18 張）、`sw.js`（快取 `v8`→`v9`，讓使用者立即取得新圖）
- 規模：大型（替換大量共用素材；舊版 SVG 圖已保存在 git 歷史 `ad032da` 可還原）
- 後續批次：記憶配對、關係配對動物＋食物（進行中）
  - 已續增動物（共用 m-/a-）：`dog`、`fox`、`cat`、`duck`；`fish`→`m-fish`/`f-cat`、`flower`→`f-bee`
  - ⏸ 2026-06-07 約 02:45 觸及 ChatGPT 圖片生成 Pro 用量上限（凌晨 4:14 重設），其餘動物／食物待額度恢復後續生
