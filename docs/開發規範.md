# 🛠️ 魔法小皇宮 — 開發工作規範

> 這份文件規定我們每次開發、修改這個專案時要遵守的流程。
> 目的：**避免改壞、方便回溯、讓文件與線上網站永遠同步。**
> 線上網站：https://nicktim791113.github.io/magic-castle/

---

## 一、核心原則：每次都要做的三件事 ✅

不論修改大小，**每次**開發完成都必須完成這三件事：

1. **更新「更新紀錄」** — 在 `更新紀錄.md` 最上面新增一段，記錄這次改了什麼。
2. **更新相關文件** — 若改動影響玩法或架構，同步更新 `../README.md` 與 `開發文件.md`。
3. **推送儲存庫** — `git add → commit → push`，讓 GitHub 與線上網站一起更新。

> 「備份」是**有條件**的（見第三節），但上面這三件事**每次都要做**。

---

## 二、先判斷修改規模：小型 or 大型？

每次動手前，先判斷這次屬於哪一種：

### 🟢 小型修改（免備份）
單一檔案、不牽動其他檔案、改壞了也容易還原。例如：
- 改文字、emoji、顏色、數值
- 在現有資料陣列加一筆（多一件衣服、多一組動物配對、多一張記憶卡）
- 微調樣式、修正錯字

### 🔴 大型修改（**動手前必須先備份**）
會牽動多個檔案、改變結構、或改壞會連累其他地方。例如：
- 同時改動多個檔案
- 修改**共用檔**：`js/common.js`、`css/style.css`、`sw.js`、`manifest.webmanifest`
- 新增整個遊戲或頁面
- 重構程式、改檔名、搬移檔案、改資料夾結構
- 改動 PWA 快取清單、相對路徑等部署相關設定

> ⚖️ **拿不定主意時 → 當作大型，先備份比較安全。**

---

## 三、備份規則（只在大型修改前）

進行大型修改「**之前**」，先把目前可用的版本完整備份：

1. 在專案內建立資料夾：`backups/YYYY-MM-DD_HHMM__簡短描述/`
   - 例：`backups/2026-06-15_2130__新增拼圖遊戲/`
2. 把整個專案複製進去（排除 `.git/` 與 `backups/` 本身）。
3. 確認備份資料夾裡檔案齊全，**才開始修改**。

備份只存在本機（已被 OneDrive 雲端同步），**不會推上 GitHub**（見 `.gitignore`），以免拖累儲存庫與網站速度。

> 🛡️ 其實我們有三道防線：
> ① `backups/` 資料夾 — 大改動前最直接、看得見的還原點。
> ② GitHub — 每次 commit 都是一份雲端歷史版本。
> ③ OneDrive — 自帶檔案版本紀錄。

### 如何還原
- 簡單：把 `backups/某版本/` 裡的檔案複製回專案覆蓋即可。
- 進階：用 `git` 還原到某次 commit。

---

## 四、標準開發流程（SOP）

```
1. 判斷規模（小型 / 大型）
2. 若為大型 → 先備份到 backups/
3. 進行修改
4. 自我測試：實際打開來玩一次，確認沒壞
5. 更新「更新紀錄.md」                ← 必做
6. 更新 README / 開發文件（如有需要）   ← 必做
7. git add → commit → push           ← 必做（自動部署上線）
8. 開啟線上網址，確認更新成功
```

---

## 五、「更新紀錄」怎麼寫

每次在 `更新紀錄.md` **最上面**新增一段（最新的放最上面）：

```
## [版本號] － YYYY-MM-DD｜一句話標題
### 新增 / 修改 / 修正 / 移除
- 具體改了什麼（白話即可）
- 影響到的檔案：xxx.js、yyy.html
- 規模：小型 / 大型（大型請附上備份資料夾名稱）
```

**版本號規則**（語意化版本，簡化版）：
- 修正小錯／小調整 → 末位 +1（`0.3.0` → `0.3.1`）
- 新增功能 → 中位 +1（`0.3.1` → `0.4.0`）
- 大改版／重構 → 首位 +1（`0.4.0` → `1.0.0`）

## 六、Git／推送規範

- commit 訊息用一句話講清楚做了什麼（中文即可）：
  - `feat: 新增拼圖遊戲`、`fix: 修正記憶卡計分`、`docs: 更新說明`、`style: 調整配色`
- 一個 commit 盡量只做一件事，方便日後回溯。
- 推送後，到線上網址確認：https://nicktim791113.github.io/magic-castle/
- 改了 `sw.js` 想讓使用者立刻拿到新版 → 把 `sw.js` 裡的 `mlp-cache-v1` 版本號 +1。
