# 🏰 魔法小皇宮

一個給小朋友玩的網頁小遊戲合集，迪士尼風格、各國風情城堡入口。
純 HTML / CSS / JavaScript，**不需要安裝任何東西**，也不需要網路。

## ▶ 怎麼玩

直接用滑鼠**雙擊 `index.html`**，就會用瀏覽器打開主畫面（建議用 Edge 或 Chrome）。
從三座城堡選一個進去玩，左上角「🏰 回城堡」可以回到主畫面。

> 平板觸控也可以玩；右上角 🔊 可以開關音效。

## 🎮 三個遊戲

| 城堡入口 | 遊戲 | 玩法 |
| --- | --- | --- |
| 🕌 阿拉丁金色宮殿 | **公主換裝** | 幫小公主換髮型、禮服、鞋子、頭飾、膚色與場景。可「🎲隨機造型」「📸拍照儲存」成圖片。 |
| ❄️ 冰雪奇緣冰晶城堡 | **記憶配對** | 翻牌找一樣的圖案消除。**記憶模式**（卡牌翻面）與**視覺模式**（正面可見，給小小孩）兩種；有簡單／普通／困難。 |
| 🍎 白雪公主古典城堡 | **關係配對** | 連連看：幫小動物找到喜歡吃的東西（猴子🍌、老虎🍖、小鳥🐛…）。先點動物，再點食物。 |

## 📁 檔案結構

```
魔法小皇宮/
├── index.html      ← 主入口（三座城堡）
├── dressup.html    ← 公主換裝
├── memory.html     ← 記憶配對
├── match.html      ← 關係配對
├── css/style.css   ← 共用畫風樣式
└── js/
    ├── common.js   ← 共用：音效、彩帶、慶祝特效
    ├── dressup.js  ← 換裝（所有髮型/禮服…的圖形都在這）
    ├── memory.js   ← 記憶配對邏輯
    └── match.js    ← 關係配對邏輯
```

## 🛠 想自己加東西？

- **加新動物配對**：打開 `js/match.js`，在最上面的 `PAIRS` 陣列加一行，例如
  `{ key: "frog", a: ["🐸","青蛙"], f: ["🐛","蟲蟲"] },`
- **換記憶卡圖案**：`js/memory.js` 最上面的 `POOL` 陣列換成你喜歡的 emoji。
- **加新禮服／髮型**：`js/dressup.js` 裡的 `DRESSES`、`HAIRS` 等陣列照著現有格式加。
- **改色彩主題**：`css/style.css` 最上面的 `:root` 顏色變數。

所有圖案都用 emoji 和手繪 SVG，跨電腦都能顯示，不需要圖檔。
